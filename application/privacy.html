Google連携とデータの取扱い

このページは、予約業務システムがGoogleの情報へアクセスする目的と取扱いを説明します。

アクセスする情報と目的

  • Gmailの読み取り：許可された施設アカウントの受信メール・送信済みメールを、予約の取込、問い合わせの確認、既存の返信・送信結果の照合に使います。
  • Gmailの送信：担当者の承認、または事前に承認された設定に基づき、お客様への返信・案内や業務の通知を送ります。
  • Googleカレンダー：許可された連携先で、予約・清掃等の予定の読取、作成、変更、取消に伴う整理を行います。
  • Googleスプレッドシート：許可された対象表で、見出し・記入済み内容の確認と収支等の転記に使います。
  • アカウント情報：連携したアカウントが、施設設定と一致しているかを確認します。

保存とアクセス

システムは、予約・メール・処理の記録と接続に必要な情報を保存します。本番のこのシステム内に永続保存する業務記録と接続情報は、暗号化された保存領域で管理し、スタッフ・管理者の権限に応じてアクセスを制限します。Googleカレンダーやスプレッドシート、LINEなどの連携先へ反映した内容は、各サービス側で管理されます。接続に使うトークンや認証情報を、公開ページや使い方資料に掲載しません。

外部サービスとAI

機能の実行には、Google、稼働基盤のRailway、LINE、Square、返信案等に使うAnthropic APIを利用します。AIへ渡す情報は対象の用件・施設ルール等に絞り、鍵番号などを除外する検査を行います。検査によって全ての個人情報を必ず除去できるとの保証はしていません。システムのデータを広告、販売、汎用AIモデルの開発・学習のために利用しません。

Google APIから受け取った情報の利用と他のサービスへの転送は、Google API Services User Data Policy（Limited Useの要件を含む）に従います。

接続の停止・データの削除依頼

Googleアカウントのサードパーティ接続設定から、このアプリへの許可を取り消せます。その場合、影響する自動処理は停止します。接続を解除しただけで、既に保存した業務記録が自動的に削除されるわけではありません。保存データの確認・削除・利用停止の依頼は、施設管理者または下記窓口へご連絡ください。削除対象と、業務上残す必要がある記録を確認して対応します。
